    Team Match screens current parent opportunities and publication-eligible child topics using the same local fielded and optional hosted semantic search assets as Funding Finder. Every displayed opportunity must also pass the team-specific evidence check for every selected researcher. Archived calls are excluded. Researchers you add and imported public ORCID-linked publication metadata are stored only in this browser.

    Enhanced ordering may send a bounded aggregate of selected research keywords and theme labels. Researcher names and publication text are not sent. The hosted ranking can only reorder opportunities that already passed every-researcher local fit.
