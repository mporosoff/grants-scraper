Add an external researcher

Add a name and three to eight specific research keywords, import public publication topics with an ORCID iD, or combine both.

Faculty interests and the hand-checked agency scope map are maintained in scripts/faculty_match.py. Matching runs live against the nightly-refreshed current catalog, and archived calls are always excluded. “Broad / umbrella call” marks solicitations that span multiple sponsor topics and require subprogram-level verification. External profiles and imported public ORCID-linked publication metadata remain stored only in this browser. This internal tool remains marked no-index.
