Update researcher profile

Propose a correction to a published profile or add a missing internal or external researcher to the shared pool. Submitting does not publish a change. The current profile remains active until an administrator approves the request and the validated deployment succeeds.

What would you like to do?
Search the published directory by name or department. Results are ordered by last name. Selecting a person prefills the published profile. A stable registry ID, not the name, identifies the correction.
Optional: search ROR or enter the institution’s complete name. Only the institution search text goes to the same public ROR lookup used by Funded Awards. Affiliation remains subject to administrator review.

What will be sent

Only the fields in this form: the selected stable profile ID, name, research summary, expertise statements, ORCID, unit, optional institution name and selected ROR identity, relationship note, supporting links, optional contact email, and optional note. Browser-local teams, saved researchers, imported publication text, search history, uploaded files, and API keys are not sent.

Use only in Team Match

Stored only in this browser for Team Match. It is not submitted for administrator review or considered for the full catalog.
